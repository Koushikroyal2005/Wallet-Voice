# API reference

- `GET /api/wallet`, `/api/wallet/transactions`, `/api/wallet/ledger`
- `POST /api/bank/topups`, `/api/bank/withdrawals`
- `GET|PATCH /api/autopay/settings`
- `POST /api/merchant/payment-requests`
- `GET /api/payments`; `POST /api/payments/{id}/pay|hold`
- `POST /api/payments/batch/evaluate|confirm`
- `GET /api/events/stream`

Interactive OpenAPI documentation is available at `/docs`.
